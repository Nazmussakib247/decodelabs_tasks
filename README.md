# DecodeLabs Tasks

I am keeping each task in its own folder so the code, tests, and notes stay easy to review. Every task README explains the goal, implementation choices, setup steps, and verification performed.

## Running a task

Each task is self-contained. Open its folder and follow the README inside it for the relevant setup and test commands.

- Secrets, local environments, generated files, and credentials are excluded through `.gitignore`.
